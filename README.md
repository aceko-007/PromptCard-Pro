**PromptCard Pro** 是一个完全免费、纯本地运行、不用注册、不用联网、不上传任何数据的 AI 提示词卡片管理工具。

🚀 它是AI 时代的「第二大脑」，也是一款万能信息管理工具。

## 主要功能 ✨

有了它，平时在网上看到别人生成的好图和提示词就可以存到本地，随时可以用
### 一键复制提示词 📁

 ### MD·TXT .图片.批量导出

### 还能把整张卡片截图保存成图片



### 🧩分类体系你自己说了算

可无限自建新分类（带图标），所有标签分类都可以自由更改名字，改成适合自己的应用场景。



### 🎨什么人可以用，怎么用？

场景一：AI 绘画玩家

一条好出图的提示词，配图存在 A 处、参数存在 B 处，下次想复刻风格全靠翻聊天记录。

场景二：AI 工具重度用户

场景三：自媒体创作者

场景四：知识管理爱好者

痛点：Notion、飞书、好用但要联网要登录，数据在别人服务器上，总不放心。



去年发的1.0版本有很多BUG，现在这个版本不仅修复了BUG，还迭代了很多新功能。



### 🚀 新功能：



1、 一键转本地，1.0版本的卡片上传的图片会走 Base64 存在数据文件里，越积越大，最后软件变得很卡顿，
这次更新了存储方式，还可以一键转本地，把存储在应用中的数据变成了从外部文件夹导入，数据更小加载更快！
每个分类，每个卡片按照层级分别自动建立文件夹，每个文件夹中包含提示词和图片。

2、一个卡片中现在可以无限添加文本框，还可以一次上传多张图片、

3、添加了表格视图模式，更直观方便！



### 🚀 3 分钟上手指南 



1、装到非 C 盘    比如 D:\PromptCard

2、新建第一张卡片  填标题 → 添加提示词文本框 → 粘贴你的提示词

3、打标签   点预设标签，或自己输入 + 填链接

4、加配图  把成品图直接拖进卡片

5、改分类名   设置 → 把“模型/平台”改成你顺手的名字

6、 备份与迁移 

日常备份：在设置中导出数据就行

换电脑：把之前导出的数据重新导入，或者把整个软件文件夹拷过去，直接运行，数据完整保留 

版本升级：旧版「设置 → 数据管理 → 导出数据」→ 新版「导入数据」
